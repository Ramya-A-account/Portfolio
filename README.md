# Ramya R. — Personal Portfolio

Responsive portfolio website built with HTML, CSS, and JavaScript.

## Before publishing
- Replace the generic GitHub links in `index.html` with your actual profile and repository links.
- Check that the project descriptions accurately reflect your work.
- Add project screenshots if you have them.

## Publish with GitHub Pages
1. Create a public GitHub repository named `ramya-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait a few minutes and open the URL shown in the Pages section. It usually looks like `https://YOUR-USERNAME.github.io/ramya-portfolio/`.

Only publish information you are comfortable making public.
